# Machine Curiosity as Question Selection

A machine does not need consciousness in order to simulate a useful form of curiosity. A practical definition is: curiosity is the systematic search for high-value unknowns. The value of an unknown can be estimated by novelty, depth, epistemic tension, researchability, and generativity.

This definition turns curiosity into a control problem. The system must decide what to investigate next, not merely answer what a user asks. The important unit of progress is therefore not the answer but the improved question.

A closed-loop curiosity system should maintain memory of previous questions, criticisms, syntheses, and failed directions. Memory prevents repetition, but it can also reinforce bad ideas if the system stores weak conclusions as if they were evidence. For this reason, every memory item should include source context, score, and evaluator notes.

The philosophical risk is anthropomorphism. The system may appear curious because it produces inquiry-like behavior. But the safer claim is architectural: the system implements a loop of question generation, criticism, grounding, synthesis, memory, planning, and evaluation.
